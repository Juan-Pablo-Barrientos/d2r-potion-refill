Potion Refill for D2RMM
=======================

Potion Refill is a D2RLoader plugin. D2RMM handles its settings, but it can't
install the plugin itself, so step 2 is done by hand once.

1. Install D2RLoader (https://d2rloader.net).
2. Copy d2rl-potion-refill.dll from this folder into
   <Diablo II Resurrected folder>\d2rloader\plugins\
   D2RMM reinstalls don't touch that folder, so this is only needed once and
   again when the plugin updates.
3. Put this PotionRefill folder in D2RMM's mods folder, enable it in D2RMM,
   pick your settings, and click Install Mods.
4. Start the game with D2RLoader using D2RMM's output mod (for example, set
   default_mod = "D2RMM" in d2rloader\config\d2rloader.toml).

To check it works, open d2rloader\logs\potion-refill.log. You should see
"Using settings from the active mod" and "send=ok".
